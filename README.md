## IX 专线是什么？一句话讲清和 IPLC、IEPL 的区别

传统跨境流量要走公网，经过多个运营商层层转接，每一跳都会增加延迟和不确定性。IPLC 和 IEPL 属于物理专线，点对点直达，MKCloud 的广港 IEPL 端内延迟能做到 1~2ms 就是这个原因。

IX 专线走的是另一条路：通过互联网交换中心的 BGP Peering 实现网络互联，入口不走公网，只允许特定云厂的 BGP 网络连入。行业里一般把这类产品叫"上云互联"或 IXP 专线，MKCloud 产品列表里的叫法是"上云互联优化入口（IXP）"。

对使用者的实际差别只有两条：第一，IX 不绑定连入省份，你在哪个城市都能用；第二，你没法用自己的家用宽带直连入口，必须先登录一台云厂服务器，再从那台机器连到专线 VPS。第一条是优点，第二条是门槛，后面细说。

## 沪美 IX 和直连款怎么选？

官方知识库给过一个选型矩阵，按业务需求对应方案：基础办公、间歇上传选沪美共享；持续传输、固定速率需求选沪美独享；需要 BGP 入口选沪美 BGP；已有支持的云网络选沪美 IX。落到实际决策，可以再算一笔账。

同是 1TB 流量档，沪美 IX 是 266 元/月，上海电信直连是 428 元/月，差价 162 元。但 IX 方案你要自备一台前置云主机，各大云厂的国内轻量服务器每月几十元起步，加上管理成本，如果只用一台、月流量又小，直连款省心不少。

这几种情况 IX 更划算：

- 团队多人、多地办公，直连款的单一省份绑定会互相卡，IX 不限连入省份
- 人不在上海、广东这类入口城市，本地到直连入口的延迟拉胯，而你有现成的云厂机器
- 需要大流量档位：30TB 流量档 IX 是 5529 元，直连线最高只有 20TB，还要 5666 元
- 已经为其他业务养着阿里云或腾讯云华东机器，前置成本接近零

反过来，如果你没有任何云厂资源、就一个人用、又不想多维护一层机器，直连款 428 元的 1TB 档是更简单的选择。区间很清晰：不想折腾选直连，有云厂条件选 IX。

## 沪美 IX 能干什么、不能干什么

MKCloud 对产品边界的说明写得比较直白，这里照实转述。

适合的场景：美区店铺后台运营、海外办公远程环境、素材上传和文件传输、调用授权 API、针对美国服务的客户端测试。第三方测评对沪美方向的反馈集中在 124ms 左右的端内延迟，跨太平洋线路里属于正常水平。

不适合的场景要特别注意。出口 IP 不接受外部连入，所以不能拿它承载买家访问的公开网站、支付回调、邮件接收或游戏服务端，这些需求要另选允许入站的托管服务。另外出口是服务器 IP，官方不保证原生、住宅或流媒体解锁属性，多账号运营也别指望"一店一 IP 就绝不关联"这种承诺，官方原话是独享 IP 不能保证平台账号不被限制。

延迟数字也有讲究：124~134ms 是产品资料里的端内参考值，不等于你打开美国网站的实际耗时。完整体验由"本地到入口（或前置机）+ 跨境段 + 出口到目标服务"三段组成，评估时应该拿真实业务测，而不是盯着单一数字。

## 常见问题

**沪美 IX 是买台阿里云当地前置就行吗？**

云厂要对、地域要对。阿里云、腾讯云、百度云国内全网可以，火山云、华为云、UCloud 只支持华东地域。买错地域或不在支持列表的云厂，连不上入口。

**前置机的流量也走我云厂账户的流量包吗？**

是的，前置云主机自身的租用费用和流量消耗都计入你的总成本，评估 IX 方案时别漏掉这一块。

**134ms 的延迟用起来会卡吗？**

先分清端内参考和全程耗时。远程桌面操作美国 VPS 的手感取决于完整链路，建议先用真实后台任务测试。后台这类操作对 130ms 左右的延迟普遍是可用的，但别用单一数字保证所有体验。

**一台 VPS 能挂几个美区店铺？**

官方没有给出通用答案，这取决于平台政策、授权方式和你的账号管理策略。产品层面能保证的是每台独立的进出口 IP，安全层面的关联问题不在网络产品的承诺范围内。

**太平洋海缆故障会断吗？**

可能。出口运营商多不等于跨境段有独立备份，官方默认无 SLA。业务对连续性敏感的话，先在工单里确认故障处理约定再下单。

**提速后能顺便加速我的独立站吗？**

不能。沪美专线优化的是运营人员从 VPS 向美国方向的访问，买家打开你网站的走的是站点托管、CDN 和买家自己的网络，两条路互不影响。
